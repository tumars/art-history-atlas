- `npm run build` 通过：图片优化、TypeScript、内容校验与 Vite 构建。487 组图片无新增转换。
- `npm test`：18 项通过。新增两项导航行为测试覆盖嵌套动作只产生一项历史、作品 / 人物 / 搜索上下文恢复、前进后退、直接深链关闭回退、后退后新分支。

## 交互

- 通过 Chrome CDP 触摸事件模拟横拖画海：投影位置变化、页面 scrollY 保持 0、未误开大图。模拟纵滑能滚动正文。
- 搜索“梵高” → 作品 → 作者资料 → 浏览器返回：恢复作品；再次返回恢复搜索窗口与关键词。
- 大图 12 次正向 Tab、12 次反向 Tab 全部留在查看器内；Esc 返回下层搜索。首次检查发现原生窗口焦点可能越过文档，补显式首尾循环后重测通过。
- 图表查看层打开 / 关闭后原节点回到所属分区，没有复制 SVG ID。关系图人物用 Enter 进入资料并关闭图层，返回恢复关系图。
- 年表与人物图的独立查看层、关系图派系选择、目录导航均完成浏览器操作检查。
- `#p-high-ren`、`#who-van-gogh`、`#story-cezannes-table` 直接载入分别显示正确展厅、人物与故事。
- 切换手机 / 桌面宽度恢复对应 DOM 顺序；图表查看层关闭，正文选择保留。

## 验证边界

以上是本地 Chrome 模拟与代码测试，不是 iOS Safari / Android Chrome 真机验收。系统双指缩放、地址栏收缩、软键盘、系统边缘返回、VoiceOver 与 200% 文本缩放仍需真机补验。未开展用户试读，也不声称性能或学习效果指标改善。

构建有主 JS chunk 超过 500kB 的提示：当前约 504.74kB，gzip 249.82kB，含既有完整内容数据。本轮没有引入运行依赖、预加载原始大图或新的图形引擎；未把该提示当作构建失败，也未进行与交互重设计无关的打包重构。
