# 手机版（iOS 原生结构）验证记录

2026-11-07 · 对应 [设计文档 2.1 节](../design.md) 与 [移动端第三至五轮](../research/mobile-ios-redesign.md)。实现位于 `src/mobile/`。

## 检查方式

- 浏览器模拟 375×812 手机视口，浅色与深色各一遍；地址加 `?still` 关闭动效以检查静态布局（同时验证了“减少动态效果”下转场直接到位）。
- 用脚本逐项点击并读取页面栈与 `history.state`，确认路由、历史与深链接；`npm run check`、`npm test` 与 `vite build` 通过。
- `scripts/mobile.e2e.mjs` 按新结构重写（tab、导航栈、浏览器返回、sheet / 全图历史、深链接、横向溢出）。本机未安装 Playwright，这一轮没有运行它。

## 视觉审查与修正

逐页截图（浅色 19 页、深色 10 页）后修正：

- 冷启动直接进入导览或人物时，时光带在隐藏容器里绘制，读到滚动位置 0，年份变成“前 30000”并带到另一条时光带 → 先显示当前 tab 再绘制；时光带等容器有宽度、滚动位置落定后才开始读年份，被替换掉的页面不再读。
- 桌面样式的 `.mobile-shell button` 重置比单类选择器优先级高，胶囊按钮失去内边距 → 重置改用 `:where()`。
- 与桌面同名的类（`.hero`、`.btn`、`.row`、`.seg`、`.chip` 等 12 个）会继承桌面样式 → 手机版改名；“真实比例”按钮漏改 → 补上。
- 艺术中心地图海岸线几乎不可见 → 海岸用 10% 墨色填充。
- 派系页没有相遇时仍显示“相遇与交汇”空标题 → 有内容才显示。
- 理性与激情的刻度用固定灰色和棕色 → 改用主题线色与强调色，深色下可读。
- 名录写死“二十次相遇” → 按数据计数。

## 独立视觉审查

另一位审查者只看截图与设计说明，列出 14 条问题。处理如下：

| 意见 | 处理 |
|---|---|
| 图解大标题把分句拆开（“从 / 暗处浮现”） | 脉络页大标题按分句断行 |
| “同一时刻”副标题末行只剩一个字 | 改为单行省略 |
| 画海作品压在标题上 | 顶部遮罩加高到 190px，实色段到 68% |
| 内容滚到悬浮 tab 栏后面仍清晰，和 tab 文字叠在一起 | 页面底部 96px 渐隐；阅读页 110px |
| 深色画海色块像“光雾” | 深色色块不透明度 0.4 → 0.2、亮度降低；浅色 0.75 → 0.5 |
| 图解滑杆是蓝色、分段是黑胶囊、说明框是竖条 + 淡紫底 | 脉络页内把桌面变量映射到手机主题；分段与说明框改成手机样式 |
| 深色主按钮薄荷色太亮 | 深色改用深墨绿底白字 |
| 年表读数针处作品缩略图叠成一团、刻度贴着圆钮 | 缩略图最多三行、间隔 3px；刻度下移，读数针缩短 |
| 人物时光淡化的名字在深色下对比不足 | 不在世的生命线不透明度 0.5 → 0.64 |
| 地图海岸线看不见 | 海岸填色 10% → 15% |
| 派系页浏览器自带三角、文字箭头“→” | 折叠块用自绘箭头；按钮去掉“→” |
| 阅读页两张大图占满第一屏 | 图片最高 30vh（竖排 32vh） |
| 关系页只有一个人时的“足迹”像误放的标签 | 走出第二步才显示足迹 |

未采纳：正文按字换行属于中文正常排版；年代写法（“约1503”）、问号来自内容数据；人物时光底部空白是因为最多 17 人同时在世，需要 17 行；文艺复兴几条时期色带同色是按大阶段着色；截图顶部的小凸起是预览浏览器的界面，不属于页面。地图标签避让沿用上一版实现，留待后续。

## 上线后的反馈（第二轮）

- 画海只有每个时期几件代表作 → 放入全部 422 件有图作品；离屏作品 `display:none`，每 8 帧按镜头位置重新挑选（首屏约 46 件在渲染），投影与侧倾变量只在变化时写入。
- 远近关系 → 中层、远层作品轻微虚化；作品加细画框。
- 首页标题移到顶栏左侧，时期选择移到底部展签上方。
- 页面顶部的白色半圆是收起的提示条：它只上移自身高度的 150%，刘海屏安全区约 59px 时会露出下沿 → 收起时上移“自身高度 + 安全区 + 20px”并隐藏。
- 导览、人物顶部分段与内容之间加 16px。
- 正文取消两端对齐。

## 上线后的反馈（第三轮，iPhone 截图）

- 虚化太重 → 中层去掉虚化，远层 0.8px → 0.2px。
- 画海应循环 → 改用 PC 版的循环布局（`arrangeWorks` / `skyLoop`），每件作品放在离镜头最近的一圈；镜头移动数万像素后屏幕仍铺满作品。星点改为平铺背景，色块限制在固定范围。
- 段落过早换行、右侧大片空白 → 原因是 `text-wrap: pretty`（桌面样式也给所有 `p` 设了它），iOS 26 Safari 会为了行长均衡整段提前断行。手机版统一改回 `text-wrap-style: auto`；只改换行风格，不影响需要单行省略的文字。

## 主题色（第四轮）

- 浅色画海改为淡淡的细金框，选中作品的描边也用金色。
- 主题色由墨绿改为“墨色 + 金箔”。比较过三种：墨绿与“20 世纪”分组色色差约 6、群青与“文艺复兴”分组色色差约 5，墨色与七个分组色都相差很远（最近约 40）；墨色文字对比度 15.8，金箔加深到 `#8a6a26` 后在白底上 4.6。时光带上关系人的描边改为中性墨线，金色只留给当前选中的人。

## 启动画面与卡片（第五轮）

- 手机打开时原来先闪一下桌面骨架，再出现一行无样式的“正在打开画间…”，然后画海空画框逐个出现。现在 `index.html` 头部按与 `main.ts` 相同的条件判断手机，立刻隐藏桌面骨架，显示写在页面里的启动画面：与画海同色的底（浅色展厅墙、深色夜空）、一件缓慢漂浮的金框小画、站名、副标题和一条金色进度线；状态栏颜色同步。页层就绪后等首屏图片解码（最多 1.2 秒）再淡出；加载失败时启动画面改为提示检查网络后刷新。桌面版直接移除启动画面。
- 人物时光的横滑卡片顶部有空白：卡片是 button，被拉到同排最高的高度后内容垂直居中。时光卡、故事卡、相遇卡、作品卡改为从顶部排起。
