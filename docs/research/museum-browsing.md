# 按博物馆 / 城市看画：需求调研与设计方案

2026-11-07 · 第一阶段已在手机版实现（入口放在导览第四段，必看按故事与年表自动选，桌面版暂不加入口），现状见 [设计文档 2.1 节与第 3 节](../design.md)。数据模型与原方案有一处不同，见 4.3。上线后手机版的“展厅”改叫“时期”，下文的“按展厅看”在页面上是“按时期看”。

## 1. 为什么需要

现在画间只能按时期（展厅、年表）、按人、按故事找画。但很多人接触西方艺术的入口是一次具体的出行：“下周去巴黎，卢浮宫和奥赛里有哪些值得看？”“在佛罗伦萨待三天，哪些教堂里有壁画？”“站在这幅画前，想知道它在讲什么。”这些问题都以“地点”开头，目前画间回答不了：作品页的“收藏”只是一行文字，点不进去，也看不到同一个地方还有什么。

## 2. 调研

**谁在什么时候需要。** Falk 的博物馆观众研究把观众动机分为探索者、陪同者（带家人朋友）、体验寻求者（打卡名作）、专业 / 爱好者、充电者五类（[Falk 2006](https://pacificsciencecenter.org/wp-content/uploads/2022/11/falk-2006-visitor-motivations.pdf)、[Walker Art Center 的介绍](https://walkerart.org/magazine/why-do-we-go-to-museums)）。对画间来说最相关的是：

- **体验寻求者 / 陪同者**：行前想知道“必看的是哪几件”，到了馆里按图索骥。
- **探索者 / 爱好者**：想知道一个馆为什么重要、强在哪个时代，回来后还想回顾看过的。

**行前与馆内都会用手机。** V&A 的观众调查发现约三分之二观众带智能手机进馆，网站数据显示手机也被用于行前决策；“按具体作品或馆藏线索查找信息”被认为是行前和馆内都值得加强的方向（[Lucidea 引述的 V&A 研究](https://lucidea.com/blog/museums-and-mobile-a-huge-opportunity-for-digital-visitor-service/)）。国家美术馆的调查也指出，信息缩水的独立手机站已不适合用户需要，行前内容应与完整内容一致（同上）。

**同类产品。** Smartify 提供扫描识别作品、语音导览、馆内路线与个人收藏，但覆盖范围取决于合作馆（[Smartify 介绍](https://www.insidehook.com/article/arts-entertainment/smartify-shazam-for-art)、[The Spaces](https://thespaces.com/will-smartify-art-app-change-gallery-experience-forever/)）。画间不是某个馆的官方导览，优势在于跨馆、跨时代的联系：同一件作品可以连到时代、人物和故事。

## 3. 数据现状

423 件作品的 `location` 是自由文本，共 172 种写法，其中 114 种只出现一次。

| 情况 | 件数（约） | 例子 |
|---|---|---|
| 收藏最多的 10 处 | 160（38%） | 巴黎卢浮宫 40、奥赛 29、伦敦国家美术馆 22、普拉多 16、MoMA 11 |
| 前 40 处 | 273（65%） | |
| 教堂、礼拜堂等原址 | 47 | 布兰卡奇礼拜堂、斯克罗威尼礼拜堂、西斯廷礼拜堂 |
| 只有城市或遗址 | 25 | “罗马”“佛罗伦萨”“埃及吉萨”“雅典卫城” |
| 失传、多处收藏、印本 | 45 | “已失传”“版画，多家博物馆藏有印本” |

按城市：巴黎 85、佛罗伦萨 45、伦敦 37、纽约 27、罗马 24（另梵蒂冈 17）、马德里 20、威尼斯 14。

由此得出两点：

1. **城市是更自然的第一层。** 佛罗伦萨、罗马、威尼斯的大量作品在教堂和原址里，只按“博物馆”组织会漏掉它们；去旅行的人也是先想城市，再想去哪几个馆。
2. **需要把地点变成实体。** 同一处有多种写法（斯克罗威尼 / 斯克罗韦尼、提森 / 蒂森），同一馆有子位置（梵蒂冈博物馆 / 拉斐尔房间 / 绘画馆 / 签字厅），同一机构有两种叫法（芝加哥艺术博物馆 / 芝加哥艺术学院）。自由文本没法可靠地聚合。

## 4. 设计方案

### 4.1 场景与对应功能

| 场景 | 用户想要 | 方案 |
|---|---|---|
| 行前规划 | 这个城市 / 这个馆里，画间收录了哪些、必看哪几件 | 城市页、馆页的“必看”；一键收藏，收藏页可按馆分组 |
| 在馆内 | 快速找到眼前这幅，读看点 | 馆页内搜索；作品按时期分组，名字可搜；作品页大字标出所在馆 |
| 了解一个馆 | 这个馆强在哪个时代、有哪些人 | 馆页的时代分布条与“这里的艺术家” |
| 从作品出发 | 同一个馆还有什么 | 作品页“收藏”可点进馆页；“同馆还有”横滑 |
| 闲逛 | 换个角度看画 | 画海可按馆筛选，变成“卢浮宫的画海” |

### 4.2 信息结构

- **入口**：导览的分段增加“去哪看”（年表 · 展厅 · 故事 · 去哪看）。名字用动作而不用“馆藏”，因为里面也包括教堂和原址。
- **去哪看（根页）**：
  - 顶部搜索框：找城市、博物馆或教堂。
  - “作品最多的地方”横滑卡片：封面用该馆最有名的一件，写馆名、城市、“画间收录 40 件”。
  - “按城市”分组列表：按国家排序，每个城市一行（作品数、地点数），点进城市页。
  - 末尾一行“不在某个馆里的作品”：失传、多处收藏、私人收藏，诚实列出。
- **城市页**：城市名与国家；地点列表分“博物馆”与“教堂和原址”两组，每行显示作品数和一件缩略图；“这座城市的画”按时期分组的作品格；可选：用现有海岸线底图画一张小地图，点位大小按作品数。
- **馆页（或教堂 / 原址页）**：
  - 头图用该馆最有名的作品，馆名（中文与原文）、城市、类型标签。
  - 一行事实：画间收录 N 件 · 时间跨度 · 官网 · 在地图中打开。
  - **必看**：出现在故事、年表或被设为代表作的作品，最多 6 件。
  - **时代分布**：一条按展厅分组色着色的分段条，一眼看出“奥赛几乎全是 19 世纪”。
  - **按展厅看**：作品按时期分组，可在馆内搜索。
  - **这里的艺术家**、**同城还有**。
  - 底部说明：“只列出画间收录的作品；展出、借展与闭馆以官网为准。”
- **作品页**：资料里的“收藏”变成可点的行，进入馆页；看点里增加“同馆还有”。
- **搜索**：结果增加“地点”一组（城市、博物馆、教堂）。
- **画海**：时期选择面板改为“时期 | 地点”两段，选了地点后画海只放这个地方的作品，标题副文字显示“卢浮宫 · 40 件”。

### 4.3 数据模型

新增 `content/places.json`（与体系无关，可被中国艺术史等复用）：

```json
{
  "id": "louvre",
  "name": "卢浮宫",
  "original": "Musée du Louvre",
  "city": "paris",
  "kind": "museum",
  "lat": 48.861, "lon": 2.336,
  "url": "https://www.louvre.fr/",
  "aliases": ["巴黎卢浮宫"],
  "parent": null
}
```

- `kind`：`museum`（博物馆、美术馆）、`church`（教堂、礼拜堂、修道院）、`palace`（宫殿、府邸）、`site`（遗址、广场、建筑本身）。子位置用 `parent` 挂到所属机构（拉斐尔房间 → 梵蒂冈博物馆）。
- 城市另列 `cities`：`{id, name, country, lat, lon}`。
- ~~作品增加 `place` / `placeNote`~~。实现时改为**作品不加字段**：地点用 `match` 列出与作品 `location` 完全相同的写法，用 `works` 直接指定少数作品（建筑本身、同一写法分属两馆）；不在某一处的写法列在 `unplaced` 里，分已失传、多处收藏或印本、王室或私人收藏三类。这样 423 件作品不用逐条改，新增作品沿用已有写法就自动归类；出现新写法时校验会报错，提示到 `places.json` 补上。
- `scripts/validate-content.mjs` 检查引用、坐标与网址，每件作品都要能归类，`match` 里不能留下没人用的旧写法。
- 迁移结果：172 种写法全部对上，共 68 座城市、157 处地点；梵蒂冈的地点归入罗马并标注区域，圣丹尼与马尔迈松归入巴黎并标“巴黎近郊”。只写了城市的建筑类作品（万神殿、佛罗伦萨大教堂穹顶等）按作品 id 归到建筑本身；“伦敦泰特美术馆”按作品分到泰特现代和泰特不列颠。地点暂不填坐标，等做城市小地图时再补。

### 4.4 措辞与边界

- 一律写“画间收录 N 件”，不写“馆藏 N 件”，避免让人以为这是该馆的全部收藏。
- 不提供展出位置（展厅号、楼层）和开放时间：这些数据会变，画间也不是官方导览。只给官网链接，并提醒以官网为准。
- 不做扫描识别。馆内场景靠馆页内搜索和按时期分组来解决。

### 4.5 分阶段

1. **第一阶段**：`places.json` 与迁移（先覆盖前 40 处，约 65% 的作品）；导览“去哪看”；城市页与馆页；作品页、搜索的入口；内容校验。
2. **第二阶段**：画海按地点筛选；城市小地图；收藏页按馆分组。
3. **第三阶段（视反馈）**：桌面版的对应入口；离线缓存，方便在馆内信号不好时使用。

## 5. 已确认

- 入口放在导览的第四个分段“去哪看”。
- “必看”自动选：出现在看画故事里的优先，其次是年表代表作，同分按年份，最多 6 件；作品不多于 4 件的地点不单列必看。
- 第一阶段只做手机版。原方案里根页的独立搜索框没有做，改为全局搜索第一组显示地点（城市、国家、馆名、原文名）。
