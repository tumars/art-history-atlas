# 十八张图解复查

日期：2026-11-04。范围：十八间展厅的图解标题、观察提示、演示机制、反馈、结论与作品关联。实现约定见 [设计文档](../design.md#4-交互图解srcdiagrams)。

## 后续决定

2026-11-04：根据使用反馈，移除史前照明图解及实现。它虽然能解释照明范围，却没有帮助理解史前艺术，改换标题仍未解决价值不足的问题。现为 18 间展厅、17 张图解；图解不再是每个展厅的必选项。随后根据文案反馈，史前介绍展开狩猎祈愿、仪式空间、故事与经验传递等猜测，以“可能”“一种解释是”标明推测，避免只说没有定论而不给读者具体内容。以下保留上一轮复查过程作为记录。

## 这次要解决的问题

旧版有些标题提出历史原因，动画却只展示视觉现象；有些图能操作，但没有明确的比较结果。洞窟图是典型：照亮动物不能解释“为什么在最深处作画”，而“都在最深处”本身也不是可靠前提。

统一采用“问题 → 观察 → 比较 → 解释 → 原作核对”。对暂时没有定论的原因明确保留不确定性；对可以看见的变化，给出具体解释。没有增加测验、评分或新交互框架。

## 逐图结论与调整

| 图解 | 旧问题 | 调整与学习结果 |
|---|---|---|
| 史前 | 用照明动画回答选址动机，暗示壁画都在最深处 | 标题改问无日光区如何观看；增加熄灯比较；区分石灯实物与仍有争议的用途、选址解释 |
| 埃及 | “心里知道／眼睛看到”容易成为对古人心理的断言 | 比较组合视角与单一侧面，解释可辨认特征与身份尺度，注明时代与用途差异 |
| 希腊 | 连续年代滑块与姿态插值造成精确演进的错觉 | 改成三个姿态示例，比较承重及肩胯方向；角度只属于示意，不是雕像测量 |
| 罗马 | 任意跨度阈值让梁断、拱始终稳，误导结构原理 | 重画梁的拉压与拱的压力路径，切换侧向支承条件，不模拟工程极限 |
| 拜占庭 | 只有闪光，缺少解释闪光来源的对照 | 比较不同朝向与一致朝向的嵌片；光源改变时，反光方向决定亮暗分布 |
| 哥特 | 尖拱、飞扶壁好像能独自代替全部墙体 | 补竖向荷载，说明肋架、柱墩与侧向支承共同工作，不把罗马式简化为只靠厚墙 |
| 早期文复 | “平行线汇聚”范围过宽，只支持直接拖动 | 限定同一纵深方向；加左右、高度滑块与复位，保留横向边线作对照 |
| 盛期文复 | 整张脸模糊被当成晕涂法 | 只调整眼嘴局部边缘，保留整体形体；说明这是感知比较，不是实际绘制配方 |
| 威尼斯 | 素描与色彩被写成互斥画派，以及单线传承 | 比较两种造型侧重，删除谱系箭头；线条、明暗与色彩都能塑造体积 |
| 北方文复 | 层数越多高光越亮，蛋彩与油画被绝对对立 | 去掉自动增强高光，说明透明层与底层共同影响颜色且可能变暗；材料性质保留条件 |
| 巴洛克 | 移动光源旁另放无关构图，使问题失焦 | 集中展示方向、投影与明暗背景；加滑块，直接比较受光边缘与背景反差 |
| 洛可可 | 静态风格清单，容易把例外排除 | 增加先看形式、再看场所用途的分步比较；注明色板线条只是常见倾向 |
| 新古典 | 自画骨架脱离原作，“直线理性／曲线女性”过度归纳 | 直接叠加《荷拉斯兄弟之誓》原画，观察手剑汇聚与姿态对照，辅助线可关闭 |
| 浪漫 | 双三角形示意不能让人看见原画的情绪和细节 | 使用《梅杜萨之筏》原画；分开上升节奏与结构标注，回看前景、暗海、远船 |
| 现实 | 风俗画被放在最低等级，题材等级与画幅规则混淆 | 恢复五类次序；呈现《奥尔南的葬礼》及同尺度人形，解释普通村民获得庄严巨幅呈现 |
| 印象 | 精确时钟、固定互补色公式、一次完成的说法过度简化 | 改为光照情境，比较环境色与只降明度；说明系列画也经历反复观察与画室加工 |
| 后印象 | 每位画家通向一个流派；蓝黄点必然混绿 | 改成四种可选择的探索，点阵保持颜色比例比较细密程度；不保证特定混色结果 |
| 现代 | 颜色像唯一源头，时间带缺少明确阅读任务 | 选择后列出同期流派；颜色仅表示讨论侧重，起止为约略阶段，重叠不证明相互影响 |

所有图解均添加作品回看入口。原作构图保留图片完整比例及来源；范围说明放在会引起误解的位置，避免仅在页脚统一免责。

## 核对资料

- 洞窟：[法国文化部：Lighting](https://archeologie.culture.gouv.fr/lascaux/en/lighting)、[Interpretations](https://archeologie.culture.gouv.fr/lascaux/en/interpretations)。分别核对照明证据与解释争议。
- 建筑：[Smarthistory：Gothic architecture](https://smarthistory.org/gothic-architecture-an-introduction/)。核对哥特支承系统。
- 材料：[英国国家美术馆：Sfumato](https://www.nationalgallery.org.uk/paintings/glossary/sfumato)、[Glaze](https://www.nationalgallery.org.uk/paintings/glossary/glaze)。区分局部柔化、透明层与整个图像的模糊滤镜。
- 风格：[V&A：Baroque](https://www.vam.ac.uk/articles/the-baroque-style)、[Rococo](https://www.vam.ac.uk/articles/the-rococo-style-an-introduction)。核对使用场景与形式倾向。
- 原作：[Smarthistory：Oath of the Horatii](https://smarthistory.org/jacques-louis-david-oath-of-the-horatii/)、[Raft of the Medusa](https://smarthistory.org/theodore-gericault-raft-of-the-medusa/)。结合实际图片检查构图标注。
- 现实主义：[奥赛博物馆：Un enterrement à Ornans](https://www.musee-orsay.fr/en/artworks/un-enterrement-ornans-924)。核对 315 × 668 cm 与普通人物的巨幅呈现。
- 莫奈：[芝加哥艺术博物馆：Stack of Wheat](https://publications.artic.edu/node/135598)。核对系列、反复绘制及画室工作。
- 点彩：[英国国家美术馆：Pointillist](https://www.nationalgallery.org.uk/paintings/glossary/pointillist)、[Khan Academy：Neo-Impressionist color theory](https://www.khanacademy.org/humanities/becoming-modern/avant-garde-france/post-impressionism/a/neo-impressionist-color-theory)。区分历史理论、并置颜色和实际感知结果。
