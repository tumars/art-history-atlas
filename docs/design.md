# 画间 · 设计文档

> 文档即代码：页面的功能、数据结构、交互规则以本文为准。改代码或内容结构时同步改这里，并在文末记一笔变更。

## 1. 定位

- **手机整体重构（2026-11-06，已实现）**：[艺术 App 调研与页面化方案](research/mobile-app-redesign.md) · [设计原型](prototypes/mobile-native.html) · [本轮实现验证](verification/mobile-native.md)。手机正式入口改为“画海 / 导览 / 探索 / 收藏”四个根页面；第 2.1 节记录当前实现。上一轮长卷适配保留为[历史研究](research/mobile-redesign.md)，不再作为手机入口规范。

- **是什么**：一部可以动手玩的艺术史。先在“时间全景”里看艺术时期、历史大事、代表作品和几条背景历史如何对齐，再进入每个时期的“展厅”，通过作品、介绍和适合该主题的交互图解理解艺术。
- **原则**：能画出来的不用文字说；图解可选，只有能帮助理解具体艺术问题时才添加；作品尽量配图，核对作品身份并保留图片来源和权利说明。
- **来源**：项目起于一份《大话西方艺术史》（意公子）的读书复盘页，开源时不再绑定这本书：文字内容按通行艺术史知识重写整理，这本书和《艺术的故事》一起列为推荐阅读。
- **研究参考**：[大众艺术史读物调研与阅读体验建议](research/art-books.md)（2026-11-03），比较叙事、作品细读与人物覆盖。已落地五篇短故事、四条现代艺术路线、六位人物及十二件作品；具体规范见下文。小创作、语音导览与普通读者试读留待后续。
- **通用性**：内容与代码分离。时期、作品、事件、背景历史都是 `content/` 下的 JSON，改数据就能增删内容；“体系”（tradition）是一级概念，目前只有西方艺术史，结构上可以加入中国艺术史等其他体系。

## 2. 页面结构（自上而下）

站名 **画间**（Huajian）。固定副标题：**在画作之间，读懂西方艺术。** PC 与手机的品牌、首页、关于和浏览器标题统一；名称与副标题分开排版。宣传文案可用“漫游三万年，读懂西方艺术。”，不替代固定副标题。品牌文字以 `content/site.json` 为统一来源；历史版本记录保留旧名。

0. **顶栏**（固定在顶部）：站名、分区索引（罗马数字 I–VIII，滚动时高亮当前分区）、主题切换（跟随系统 / 浅色 / 深色）、GitHub 链接。顶栏下沿有一条细的阅读进度线。多于一个体系时出现体系切换。
   - **全站搜索**：顶栏“搜索”打开检索窗口，输入即搜索当前体系的全部作品（含无图作品和人物补充作品）与人物；支持作品名、作者、人物中英文名，忽略大小写、重音与姓名间隔符，空格可组合关键词。可筛选全部、作品或人物，名称完全匹配优先。结果显示缩略图、名称和作者/西文名，显示数量与空状态；空输入提示如何检索。作品打开共用大图并可在本次作品结果中前后浏览，人物跳到共用资料卡。原生模态窗口支持 Tab 与 Esc，关闭返回搜索入口；再次打开保留关键词与筛选。手机与浅深色主题共用同一入口。
1. **序厅 · 浮空画海**：深蓝夜色中，作品像孔明灯一样散落悬浮；大小、明暗、位置和缓慢摆动形成远近层次。使用普通图片元素和 CSS 动画，移除 WebGL 三维长廊。
   - 全部有图作品都进入同一片大于屏幕、横纵首尾相接的循环空间，目前共 422 件，包含人物补充作品。按时期顺序沿折返的行稳定散布，每行均匀分配，混合远、中、近三层深度；屏幕只呈现其中一小片，拖过边缘后自然接回另一端，可一直探索。每幅画投影到镜头附近的一圈，换圈发生在视口外，不重建图片；仅给视口附近的图片设置来源，离屏节点不绘制，大图按需加载。
   - 左上是站名、口号与导语；底部是当前作品的年代、名称、作者和时期。悬停、键盘聚焦、左右按钮和时期索引都能更新当前作品；键盘 ←/→ 仅在序厅内生效。
   - 图片保持稳定，不循环换图或闪烁。静止时只做幅度很小、错开周期的漂浮；拖动时按深度产生不同幅度的位移，叠加随速度变化的轻摆，松手后短暂惯性滑停。拉近、拉远视距使图片的尺寸、明暗与透明度连续变化，靠近视野中心略微放大；图片首次载入轻淡入。悬停或聚焦时暂停单幅漂浮，暂停按钮控制整片漂浮；移出视口、页面切到后台时自动暂停。
   - 开启“减少动态效果”时关闭自动漂浮、惯性、轻摆及镜头缓动，保留直接拖动、定位与视距调整；系统偏好变化即时生效。切换浅色/深色主题不重建图片，序厅始终使用暗场。
   - 点击作品打开大图，可连续浏览全部有图作品。底部时期索引可横向滚动，选择后镜头就近飞向该时期代表作；左右按钮与键盘循环遍历整个画海，末件接首件。绕行多圈后定位也选择最近的一圈，不返回初始镜头位置。视距按钮及 +/- 键调整远近，并尽量保持当前作品在画面中的位置；页面滚轮照常滚动正文。
   - 鼠标可从空白或作品上按住拖动，无边界地横纵循环探索；标题、展签和控件固定。手机横拖循环探索、纵滑滚动正文，并保留浏览器双指缩放。移动超过 6px 才算拖动，松手不误开大图；拖动中暂停漂浮，松手恢复。跨接缝时景差、惯性与摆动连续；滑停后展签选择视野焦点附近的作品。星光粒子也在视口外循环接回，连续绕行后保持密度。
2. **I · 年表**（原时间全景）：背景行、历史大事、代表作品与艺术时期共用时间轴，视觉上统一到新的字体与配色。
   - **艺术中心的接力地图**：13 个主线站点、14 个地理地点，覆盖法国和西班牙的洞穴、尼罗河流域、欧洲各城与纽约。站点、年代、介绍和经纬度写在 `tradition.json` 的 `relay` 中；威尼斯与尼德兰分别呈现，巴洛克的多个中心同时高亮，罗马、巴黎可查看多个相关时期。连线仅表达叙事主线，页面说明各地并行发展，不代表唯一中心或直接传播路径。
   - 默认显示欧洲与地中海，选择纽约自动平滑展开到跨大西洋全景；支持视野预设、缩放、鼠标拖动、手机横拖，手机纵滑仍滚动正文。城市点可点击、键盘聚焦后用 Enter / 空格选择；底部站点索引、前后按钮和介绍联动，单独的展厅入口跳转到对应时期。
   - 选择站点时曲线逐段绘出，光点沿当前路线移动，当前城市缓慢呼吸。播放接力每 3.2 秒推进一站，到终点停止；手动选择、拖图、离屏或切后台停止播放。减少动态效果时取消镜头缓动、路线与光点动画，手动选择及主动播放仍可使用。
   - 底图使用本地 Natural Earth 1:110m 公有领域海岸线，经简化后按统一经纬坐标投影为 SVG，不展示现代政治边界，不需要地图服务或在线瓦片。保留可见来源链接；浅深色主题均沿用全站变量，手机将介绍排到地图下方。
3. **II · 展厅**：
   - 时期导航改为细长的“展厅索引”：编号、时期名、起始年，当前项下方金色细线；横向滚动只滚动索引本身。
   - 左栏：罗马式大号编号、中文时期名、西文名（斜体衬线）、年代、主线（引文样式）、关键词、要点、历史背景。
   - 右栏：作品挂在“墙面”上（浅色衬底、柔和投影），下方是博物馆说明牌样式的展签：作者、作品名、年代 · 材质 · 馆藏、看点、图片署名；再下方是本厅作品缩略图。
   - 切换展厅时内容淡入（减少动态效果时直接切换）。
   - 深链接：`#p-<时期id>` 直接打开某个展厅，切换展厅时同步更新地址。
4. **III · 人物**（艺术派系、同时代人与关系）：
   - **艺术派系视图**：默认入口按 29 个画派、艺术运动与历史传统组织全部 67 位人物。一人可归属多类；成员与赞助、同路人、风格先声分开列出，不把资助者当成该派艺术家。沿用已有视图偏好，首次访问默认“艺术派系”。
   - 左侧按历史大阶段排列派系索引，右侧显示派系年代、中英文名、特点与代表人物头像列表；每个人可查看其他归属。支持按中文姓名、西文姓名、派系中文名或英文名搜索；搜索保留该派的其他人物作为上下文，并突出匹配者。无结果时明确显示空状态。手机改用分组下拉选择派系，人物排成两列。
   - 点人物打开下方共用的人物资料卡；卡头的“艺术派系与关联”标签可反向切到对应分类。切换人物时同步高亮，若当前派系包含此人则保留当前分类，否则移到其所属分类。其他地域、时代与圈子描述作为次要背景保留。各类配有中文维基百科入口。
   - **生命线图**：每位人物一条横线，从出生画到去世，颜色取所属时期的大阶段色；生卒年不确定的用虚线端头。时间轴单独分段：前 500–1250 压缩在左侧约 15%，1250–1990 占其余部分（人物几乎都在这一段）。人物按出生年排序，用“车道”紧凑排布：同一行里时间不重叠（含名字宽度）的人共用一行。左侧刻度只标大段年份。
   - **扫描线**：鼠标在图上移动（手机上触摸拖动）时出现一条竖线，标出年份；这一年在世的人亮起，其余变淡；图下一行写出“某年在世：……”。
   - **相遇点**：真实发生过的交集画成金色小菱形，菱形之间用细竖线连起相关的人，比如 1504 年佛罗伦萨的达·芬奇与米开朗基罗、1888 年阿尔的梵高与高更。点相遇点在卡片区显示这段故事。
   - **三种视图**：分区标题右侧切换“艺术派系 / 生命线 / 关系图”，选择记在浏览器里（`aha.peopleView`）。三种视图共用下方的人物卡片和当前选中的人。
   - **关系图**：
     - 与艺术派系联动：派系列表可点“在关系图中查看”，从派系列表切换关系图也带入当前分类。图上提供按历史阶段分组的派系选择和“全部人物”入口，切换派系同步列表的当前分类。
     - 默认仅展示所选派系的成员与明确身份的相关人物、以及他们之间已收录的关系，并重新紧凑排布；“显示跨派系关系”可扩展到这些人物的一层直接关系，外部人物以虚线头像圈和“跨派系人物”标注，不把他们当作该派成员。赞助人、同路人等继续显示具体身份。无关系时显示说明，不推断或补造连线。
     - 图上摘要保留派系特点，并统计艺术家、相关人物、跨派系人物及当前开启的连线数量；五种关系开关作用于筛选后的图，切换开关保持布局稳定。点人物仍更新共用资料卡，不改变当前图的派系范围。少量人物使用较小画布，手机在图内横向滚动。
     - 每人一个圆形节点（肖像，外圈为时期色），名字在下方。横向按出生先后等距排开（不按真实年份比例，否则 19 世纪会挤成一团），从左往右仍是时间顺序，顶部刻度标出“该年以后出生的第一人”的位置；纵向位置由排布算法决定：有关系的人互相靠近，节点之间互相排斥、不重叠，横向只允许在自己的位置附近小幅挪动。排布在页面加载时一次算完（固定初值，结果稳定），不做持续动画。
     - 五种连线，颜色和线型各不相同，图例可逐类开关：师承（实线、群青，带箭头指向学生）、影响（虚线、灰，指向被影响者）、对手（红色实线）、赞助（金色实线，指向受资助者）、相遇（金色点线，同一次相遇中在场的人两两相连；两人之间已有其他关系时不再画相遇线）。
     - 鼠标悬停或键盘聚焦某个节点时，只突出他和直接相连的人与线，其余变淡；离开后回到当前选中的人。点节点选中此人，下方卡片随之更新。连线悬停显示“甲 → 乙：关系”。
     - 选中一次相遇时，突出在场的人和他们之间的线。
     - 手机上同样横向滚动（最小宽度 900px）。
   - **人物卡片**（点一条生命线或一个节点）：在图下方原位展开，不弹窗。
     - 卡头：肖像（圆形裁切，无图时用姓氏首字）、身份、姓名与西文名、生卒年与享年、主要城市、可切换分类的派系及关联身份标签、其他背景、一句话介绍。
     - 下面分四个页签，切换人物时停留在同一个页签：
       - **概览**：评价（同代人与后世怎么看他，2–4 句）、一句有出处的名言（只收出处可靠的）、两三条看点、“去××展厅”和维基百科链接。
       - **生平**：竖排时间线，每条是“年份 · 当时几岁 · 一句话”；他参与过的相遇用金色标记穿插在其中，点了打开相遇卡。
       - **作品**：每一条清单项必须关联完整作品资料，展示作品名、年代、现藏地和介绍；有图时显示完整比例缩略图，点击标题或图片打开详情。失传作品可使用身份可核对的古代摹本或历史复原图，并明确标注所示版本，不能当成原作照片；不以其他同名作品替代。作品资料统一链接中文维基百科，图片来源另列原始文件页或馆藏页。清单之外、本站收录的创作补在末尾。赞助人、收藏家关联的作品另列真实创作者，不能把关联关系当作创作关系。
       - **关系**：“师承与来源 → 本人 → 学生与后来者”关系链、对手、赞助人、资助过的人、相遇列表，人名可点击切换。
     - 选中某人时，生命线上他的那条线标出生平节点（小圆点）。
   - **与其他模块打通**：展厅说明牌和大图里的作者名可点击，点了滚到人物区并打开该人卡片。深链接 `#who-<人物id>`。
   - 手机上生命线图横向滚动（最小宽度 900px），打开某人或某次相遇时自动滚到对应年代；轻点图上任意位置即显示那一年的扫描线。卡片单栏。
5. **IV · 理性与激情**（钟摆图，体系里的说明文字放在图下）、**V · 并置**（原对照组）：内容不变，视觉统一。
6. **VI · 三分钟看画**（`#readings`）：先比较作品，再跟随问题细看。
   - 五篇短故事入口放在并置之后的独立分区，主题为《奥林匹亚》的凝视、《圣马太蒙召》的光、塞尚的桌子、毕沙罗与塞尚、1874年自己办展。阅读区在该分区内原位展开，不遮挡作品。每篇三步：先看作品、做一次观察或比较、按需展开背景，再去下一件作品。不计分，可跳过或随时回看。
   - 每步一至两件原作，保留完整图像、作者、年代和图片署名。局部圆点及文字按钮可放大到两倍，并可回到全图；主观选择逐项回应，不判对错。当前阅读中记住已展开的说明与选择，重新打开一篇时从第一步开始。
   - 第18厅在作品之前提供颜色、形体、抽象、艺术边界四条独立路线，不要求顺序完成。每厅新增一个具体的开场问题，接续原有时代主线。
   - 展签、大图、藏品、人物概览与关系页、相关并置和相遇提供对应故事入口。已有关系若关联故事，图上叠加可点击的金色连线，随派系范围、关系开关及人物高亮更新。关系图上方只放派系介绍与关系数量，不展示故事跳转列表；故事仍可从图中连线和“三分钟看画”分区进入。主题比较不自动推断人物影响关系。
   - 深链接 `#story-<id>` 可直达阅读；切步聚焦标题，收起后返回入口焦点。故事连线支持 Enter / 空格，任务可用按钮操作，不依赖拖动。手机上下排图文，深色沿用全站变量；减少动态效果时取消图片缩放过渡和滚动缓动。下一站直接滚到对应作品展墙。
   - 每篇有可展开的资料出处，区分画面观察、解释与史实；争议解释不设唯一答案。作品、人物及相遇可另附馆藏或研究来源，百科入口仍使用中文维基百科。
7. **VII · 尺度**（原画有多大）：比较原作与人体的比例。
8. **VIII · 藏品**（看片台）：只占约一屏，一次细看一件。
   - 上方：左边是作品大图（墙面色衬底，按原始比例完整显示，点图打开大图），右边是说明牌：所属时期（阶段色短线，点了跳到该展厅）、作者、作品名、年代 · 材质 · 馆藏、看点、图片署名，再下面是 ← n / N → 和“去××展厅”。
   - 中间：时期概览条，每个时期一段，宽度按作品数；当前时期加粗并显示阶段色，点某段跳到该时期第一件。
   - 下方：缩略图带，全部作品按时期、年份排成一条可横向滚动的胶片，按时期分组，组名吸附在左侧；当前作品上浮并加阶段色描边，切换时只滚动胶片本身，不带动页面。
   - 区域在视口中部时，键盘 ←/→ 换一件；手机上在大图上左右滑动换一件。切换时内容轻微淡入，减少动态效果时直接切换。
   - 大图列表为全部作品（与看片台顺序一致）。
   - 为什么不用瀑布流：68 件作品平铺要滚好几屏，看不出作品与时代的对应关系；看片台把“时代位置”（概览条 + 胶片分组）和“细看一件”放在同一屏里。
9. **大图**：使用原生模态 dialog，桌面端左图右文，手机上下排列。←/→ 或按钮在当前列表里前后切换，显示“第 n / N 件”；点图片或“放大 / 适应屏幕”按钮切换原尺寸与全图；返回按钮、Esc 与浏览器返回回到来源，点击空白不关闭。Tab 焦点循环限定在查看器内。展签含署名，可跳到所在展厅。
10. **页脚**：内容说明、图片来源与授权、推荐阅读、许可证与源码链接。站点介绍下方展示作者的 X 链接（`X @Tumars`，指向 `https://x.com/Tumars`），新窗口打开，沿用页脚链接样式。

### 文案原则

- 控件标签表达如何操作，观察提示表达为什么操作、应比较什么。不重复泛泛的“点击这里”，但允许必要的比较步骤与键盘无障碍说明。
- 少用公式化句式：避免“X：Y”的标语式冒号句、“不是……而是……”、“……的代名词 / 集大成 / 宣言 / 奇迹”这类套话，也不用破折号。
- 短句、具体。写人做了什么、画里有什么、数字是多少，不写空泛的评价。
- 对没有定论的问题，展开具体解释与猜测，让读者知道它们在说什么；用“一种解释是”“可能”等自然措辞区分推测，不反复强调“无法证明”“尚无统一答案”，也不把猜测写成已知事实。
- 页脚统一说明图解包含原理示意与原作标注；会影响理解的边界必须就近说明，例如示意不等于工程计算、光照不等于选址动机、构图线不等于唯一读法。
- 时期主线（thesis）一到两句，说清这个时期最核心的变化；过渡语（bridge）只交代原因，下一间的名字由页面自动补上。

## 2.1 手机版：iOS 原生结构（2026-11-07）

此节覆盖上面的桌面长卷布局。启动时，宽度 ≤700px 或粗指针设备屏幕短边 ≤700px 进入独立手机页层（`src/mobile/app.js` + `mobile.css`），桌面仍使用原长卷；桌面窗口跨越断点后刷新才重新选择入口。方案、调研与历轮取舍见 [移动端第三至五轮](research/mobile-ios-redesign.md)，可操作原型保留在 `docs/prototypes/mobile-ios.*`。上一版（画海 / 导览 / 探索 / 收藏，2026-11-06）的记录见[历史研究](research/mobile-app-redesign.md)与[验证](verification/mobile-native.md)。

- **结构**：底部悬浮玻璃 tab 栏“画海 / 导览 / 人物 / 收藏”，右侧独立的搜索圆按钮，点开后 tab 栏收成一枚返回按钮、搜索框展开。四个根页面不放大标题，只在状态栏背后留一条滚动时出现的玻璃条。二级页面（作品、人物、展厅、故事、脉络、关于）有玻璃圆返回按钮，标题随滚动出现。每个 tab 保留自己的页面栈；重复点当前 tab 回根页或回顶部。
- **转场与手势**：推入带视差，缩略图到作品页是缩放转场；页面任意位置右滑返回；sheet 有贴合内容 / 中 / 大三档，可拖动；长按作品出现预览与菜单（收藏、打开、作者、展厅、分享）；全图支持双指缩放、双击放大、下拉关闭和原图按需加载。减少动态效果时转场直接到位。
- **画海**：全部有图作品（目前 422 件，选择时期后为该时期作品）沿用 PC 版 `hero-space.ts` 的布局，按年代沿折返的行排开，横纵首尾相接，可以朝任意方向一直拖下去；每件只画一份，放在离镜头最近的一圈，换圈发生在屏幕外，镜头走向某件作品时也去最近的一圈。作品像孔明灯一样散在远、中、近三层，拖动有视差；离屏作品不渲染也不加载图片。星点是可平铺的背景，按图块取余平移；色块在固定范围内跟随。每件有细画框（浅色为淡淡的细金框，深色为细金边加底部暖光）和一点固定倾斜，以底边为轴轻摇，拖动时随速度侧倾；远近主要靠大小、明暗与饱和度，只有最远一层带 0.2px 的极轻虚化。选中的作品摆正、清晰，远层的会被“拉近”。浅色是白天的展厅墙（灰泥颗粒、缓慢移动的天光、跟着选中作品的射灯、随位置变化的投影），深色是夜空（两层星点、作品底部暖光）。背景三块柔边色块取自选中作品的颜色。顶栏左侧是站名与副标题（选了时期时显示时期与年代），右侧是随机与网格；时期选择在底部展签上方。网格模式按时期浏览全部作品。
- **导览**：年表 · 展厅 · 故事，默认年表。年表是可左右拖动的时光带（欧洲、中国、教会、大事、作品、时期六行，展开比例或真实比例），下方“此刻”面板随读数针更新；底部有“更多脉络”（艺术中心地图、理性与激情、并置看画、画有多大）与按时期列表。展厅为分组色卡片，展厅页有“认识这个时代”和互动图解入口。故事页可开始或继续阅读；阅读页逐步观察、选择、展开背景，纸色 / 白色 / 夜间与字号可调。
- **去哪看（导览第四段）**：按地点看画，方案与调研见 [按博物馆 / 城市看画](research/museum-browsing.md)。根页是“作品最多的地方”横滑卡片和按国家分组的城市列表（城市行写主要地点和作品数），末尾是“不在某一处的作品”（已失传、多处收藏或印本、王室或私人收藏）。城市页顶部三张作品，地点分“博物馆”与“教堂、宫殿与原址”两组，下面按展厅列出这座城市的作品。地点页：头图、原文名、“画间收录 N 件”、年代跨度、官网与地图链接；必看（出现在看画故事里的优先，其次是年表代表作，最多 6 件，作品多于 4 件时显示）、按大阶段着色的时代分布条、按展厅看、这里的艺术家、同城还有；底部说明只列画间收录的作品，开放与展出以官网为准。作品页标题下有所在地点，资料里的“现藏”可点进地点页，看点里有“同在某馆”；搜索结果第一组是地点（城市、国家、馆名、原文名）；长按菜单可去现藏地点。
- **人物**：时光 · 关系 · 名录。时光带上每条生命线带头像和名字，拖动读出年份，下方是那一年在世的人；关系是以一个人为中心的关系链，可沿足迹返回；名录有派系入口（派系与关系、派系生命线）、全部相遇和按时代分组的人物。年表与人物时光共用当前年份。
- **视觉**：中性底、实色卡片、细描边；主题色为“墨色 + 金箔”：主按钮浅色用墨色（`#1c1b1a`）、深色用骨白（`#ece6d6`），链接、选中、读数针、进度等少量强调用金箔（浅色加深为 `#8a6a26`，白底对比度 4.6；深色 `#d9b66a`），与画海的金色画框和夜空灯光呼应，也与桌面版的金箔点缀一致。不用大面积彩色，避免和七个大阶段的数据配色混淆（之前的墨绿与“20 世纪”分组色几乎相同），颜色只来自作品本身（作品等页顶部有很淡的取色）。中文标题按分句断行；正文左对齐（不用两端对齐，避免中西文混排时字距被拉开），导语用宋体。详见研究文档第 2 节。
- **收藏与设置**：收藏只存作品 id（`aha.favorites.v1`，与上一版共用）；阅读进度按故事保存在 `aha.reading.v2`（自动迁移 `aha.reading.v1`），阅读外观在 `aha.reader.v1`；存储失败时提示只在本次浏览保留。“关于画间与设置”在收藏页底部：外观（跟随系统 / 浅色 / 深色，与桌面共用 `aha.theme`）、图片来源、延伸阅读、源码与作者链接。
- **历史与深链接**：每条历史保存可序列化的页面栈；子页压栈，tab 切换与页内状态只替换当前项；sheet 与全图各占一条历史，浏览器返回先关闭它们；右滑返回与界面返回按钮同步历史。地址为 `#m/<tab>/<kind>/<id>`（kind：work、person、hall、city、place、unplaced、story、reader、context、about；`viewer` 打开作品并展开全图），兼容上一版的“探索”tab 与 `#p-*`、`#who-*`、`#story-*`、`#work-*`、`#pendulum` 等旧链接；内容不存在时显示“未找到”。刷新从当前历史项恢复。
- **样式隔离**：桌面样式表在手机上也会加载，因此手机变量挂在 `.mobile-shell` 上，与桌面同名的类改名（`whero`、`pbtn`、`lrow`、`segc`、`pchip` 等），并用 `:where()` 低优先级重置桌面的 h1–h4、按钮、链接、图片样式；互动图解仍用桌面样式。
- **待验证**：真机上的手感（拖动、视差、右滑返回与 Safari 边缘手势）、玻璃模糊与画海三层的性能、读屏与 200% 文本尚未在 iPhone 上检查；浏览器模拟的检查记录见 [手机版验证](verification/mobile-ios.md)。

```
content/
├── site.json                       站点信息、时间轴分段、体系列表、推荐阅读
├── places.json                     作品所在的城市与地点，各体系共用
├── context/                        背景行，可被任意体系引用
│   ├── europe-periods.json
│   ├── china-dynasties.json
│   └── church-history.json
└── traditions/
    └── western/                    一个体系一个目录
        ├── tradition.json          名称、大阶段配色、艺术中心接力、背景行、钟摆配置
        ├── periods.json            时期（含图解标题与说明）
        ├── works.json              作品
        ├── events.json             历史大事（按年份排序）
        ├── comparisons.json        对照组（可选）
        ├── sizes.json              画有多大（可选）
        ├── people.json             人物与相遇
        ├── readings.json           看画故事与主题路线（可选）
        ├── schools.json            人物派系：说明、成员与明确身份的关联人物
        └── movements.json          20 世纪流派表，供“现代艺术”图解使用（可选）
```

类型定义见 `src/types.ts`，`scripts/validate-content.mjs` 检查必填字段、id 唯一和引用关系（构建和 CI 都会运行）。要点：

- **年份**：数字，负数为公元前。`yearText` 是给人看的写法（如“约前 450”）。
- **时期** `Period`：可选 `question` 为开场观察问题；`id, name, short, en, span, start, end, group, mood(-2…2), thesis, keywords, points, bridge, diagram{id,title,caption}`。
- **作品** `Work`：`id`（小写字母、数字、连字符）、`title, artist, yearText, year, medium, location, summary, period`；图片选 `image.commons`（Commons 文件名）、`image.wikipedia`（英文维基文件名）或 `image.url`（馆藏图片地址）之一；馆藏图片还需 `source, author, license`，可选 `thumb`。`copyright` 仅为来源权利说明，不控制显示；真实缺图原因用 `noImageReason`；`imageNote` 说明图片所示的古代摹本、历史复原、局部或系列版本。`source` 为中文维基百科条目或中文搜索链接，内部取图文件标识仍可使用原文。`timeline: true` 出现在时间全景；`supplementary: true` 为人物扩展作品，有图时进入画海，也可从展厅、人物页及藏品区查看。
- **人物** `people.json`：`{ people: Person[], encounters: Encounter[] }`。
  - **派系** `schools.json`：`ArtSchool[]`，每类含 `id, name, en, group, span, summary, members[]`；`group` 引用大阶段，`members` 引用创作人物 id，`related?[{person, role}]` 表示赞助、先声、同路人等关联。允许一人跨多个分类，单一分类内不重复；全部人物须至少归入一类或明确关联。分类与原有 `movement` 背景标签分开维护，校验引用和完整覆盖。
  - `Person`：`id, name, en, born, died`（数字年份）、`approx?`（生卒年为约数）、`roles[]`（画家、雕塑家、建筑师、赞助人、作家……）、`period`（主要所属时期）、`cities[]`、`line`（一句话）、`points[]`（看点）、`movement[]`（流派、画派或圈子）、`life[{year, yearText?, text}]`（生平节点，按年排序）、`works[{title, year, where, work}]`（主要作品；`work` 指向本站作品 id）、`legacy`（评价）、`quote?{text, by, source}`（只收出处可靠的）、`rel{ teachers?, influences?, rivals?, patrons? }`（均为人物 id）、`wiki`（英文维基百科条目名，用于取肖像）、`portrait?: false`（不取肖像，如古代人物）。“学生”“影响了”由反向关系计算，不重复填写。
  - `Encounter`：`year, yearText?, place, people[], title, text`。
  - `Person.diedText?` 用于“1654年或以后”等无法精确给定的卒年；数字 `died` 仅供图形定位，此时不计算精确享年。人物卡及分类名单显示该说明。
  - `Work`、`Person` 与 `Encounter` 可用 `sources?: {label, url}[]` 附加事实依据；URL 使用 HTTPS，独立于作品中文百科入口和图片署名。
  - 作品通过 `by: string[]`（创作者的人物 id）挂到人物名下；`artist` 仍是显示用文字，团队作品与佚名作品可不填 `by`。`Person.works[].work` 也可关联本人委托、资助或收藏的作品，不要求本人出现在 `by` 中；同一作品复用同一记录。
- **阅读** `Reading`：`id, kind(story|route), title, deck, minutes, periods[], people[], steps[], next[], sources[]`。每步含 `title, prompt, works[1–2], context`；可选 `details[{work,label,x,y,note}]` 用原图百分比定位局部，`choices[{label,response}]` 回应主观观察。`next[{work,label}]` 是后续作品；`relations?: [人物id,人物id][]` 仅挂接已存在的真实关系或相遇。校验步骤作品、局部范围、图片署名、来源及各类引用。
- **地点** `places.json`：`cities[{id, name, country, lat, lon}]`；`places[{id, name, original?, city, area?, kind(museum|church|palace|site), url?, parent?, note?, match?[], works?[]}]`；`unplaced{lost|multiple|private: {label, match[]}}`。作品不加字段：先看地点的 `works`（作品 id，用于建筑本身，或同一写法分属两馆，如“伦敦泰特美术馆”分到泰特现代与泰特不列颠），再看 `match`（与作品 `location` 完全相同的写法，多种写法可以归到同一地点，一种写法也可以列在两个地点下表示分藏两地）；都没有的，`location` 要写在 `unplaced` 里。`location` 仍是给人看的原文，可以写到具体房间。校验检查 id、城市与所属地点引用、HTTPS 官网，每件作品都能归类，且 `match` 里没有无人使用的旧写法。归类逻辑在 `src/lib/places.ts`，有单独测试。
- **历史大事** `HistoryEvent`：`year, yearText, name, what, art, periods[]`。
- **背景行** `ContextBand`：`id, label, theme(neutral|cinnabar|violet), fields[], items[{start,end,name,short,values[]}]`，可选 `intro`（导读卡）和 `emptyBefore`（某年之前留白并标注）。条目不能重叠，重叠的朝代按统一年份切开（如隋 581、元 1279）。
- **大阶段** `Group`：`id, name, light, dark`，运行时写成 CSS 变量 `--g1…--gN`，浅色、深色主题各一套。
- **时间轴分段** `site.axis.segments`：`[起年, 止年, 起点位置, 止点位置]`。目前前 30000–前 3000 占 13%，前 3000–500 占 23%，500–1400 占 14%，1400–1970 占 50%。

## 4. 交互图解（`src/diagrams/`）

- 接口：`Diagram { html(ctx): string; init(root, ctx): void }`；`ctx` 提供当前体系数据和 `groupVar()`。注册表按体系与图解 id 查找实现。
- `diagram` 整体可省略；不为展厅数量凑图。史前展厅仅展示作品与介绍，不保留照明图解或占位。
- 每张图形成完整的学习过程：**具体问题 → 观察提示 → 可比较的操作 → 反馈与结论 → 回到作品核对**。标题只承诺图中能够解释的内容；未知原因不能靠动画假装证明。
- `periods.json` 的 `diagram` 必填 `id`、`title`、`observe`、`caption`、非空 `works: {work, label}[]`，可附 `sources: {label, url}[]`。内容校验检查必填项、作品引用与来源 URL。
- 展厅统一渲染观察提示、“从图中理解”、作品入口与折叠来源。作品入口使用已有大图查看器与署名。各图的动态反馈放在操作附近。
- 明确区分实物证据、解释和演示假设；不编造连续的年代插值、固定的物理断裂阈值或单线流派谱系。必要的限制就近写出。
- 原作构图图使用 `artwork.ts`，完整保留图片比例，百分比坐标叠加可关闭的 SVG 辅助线，复用原有图片来源。辅助线只是本站的一种阅读路径。
- 拖动透视点与巴洛克光源同时提供带标签的滑块；选择器可用键盘，现代流派行支持聚焦及 Enter/空格。图解内方向键不会触发展厅切换。窄屏下控件换行，较宽的原理图在自身容器内横向滚动，原作按屏宽缩放。

| 时期 | 核心比较 | 交互与应理解的结果 |
|---|---|---|
| 史前 | 不设图解 | 照明常识不足以帮助理解史前艺术，保留作品与介绍 |
| 古埃及 | 组合视角 / 单一侧视角 | 切换人体表现；特征的可辨认性与身份尺度属于表现惯例 |
| 古希腊 | 三种姿态 | 选择古风、古典、希腊化示例；肩胯变化与承重有关，角度不是历史测量 |
| 古罗马 | 梁的拉压、拱的压力与侧推 | 切换拱脚可靠支承 / 支承不足；稳定取决于材料、结构和约束 |
| 拜占庭 | 嵌片不同朝向 / 相同朝向 | 移动光源、切换嵌片；反光方向造成不同亮暗 |
| 罗马式与哥特式 | 开窗与支承系统 | 显示竖向与侧向荷载路径；肋架、柱墩、飞扶壁共同工作 |
| 文艺复兴早期 | 纵深方向平行线的汇聚 | 拖动或用滑块移动消失点、复位；横向线并不全部汇聚 |
| 盛期三杰 | 局部边缘清晰 / 柔和 | 改变眼嘴局部过渡；形体仍可辨，表情更含蓄，不把全脸模糊当作晕涂法 |
| 威尼斯 | 线条与明暗 / 色块关系 | 在两种造型提示间过渡；是侧重差异，不是画派互斥规则 |
| 北方文艺复兴 | 零层 / 多层透明色 | 改变层数；底色参与而亮度可能下降，不保证越叠越亮 |
| 巴洛克 | 光源位置、明暗背景 | 拖动或滑块调光源、切换背景；比较受光、投影与背景反差 |
| 洛可可 | 色彩线条与使用场景 | 先观察形式再展开语境；比较常见倾向，避免风格检测表 |
| 新古典主义 | 《荷拉斯兄弟之誓》原画 | 切换手与剑的汇聚、挺直与垂落；视觉焦点与人物情绪的关系 |
| 浪漫主义 | 《梅杜萨之筏》原画 | 切换人物上升路径、两组斜向结构；希望与危险并存 |
| 现实主义 | 题材次序与《奥尔南的葬礼》尺度 | 展开原画与同比例人形；普通人获得巨幅、庄严呈现，风俗画不是最低等级 |
| 印象派 | 光照情境与环境色 | 改变光照、比较加入环境色 / 只降低明度；不使用精确时钟或固定互补阴影公式 |
| 后印象派 | 四种探索与点彩观看 | 选择艺术家说明、改变点的细密程度；不把蓝黄混成绿或单线传承当定律 |
| 现代艺术 | 流派时间带的交叠 | 选择时间带显示同期流派；颜色表示讨论侧重，时间重合不代表影响关系 |

完整的问题与改动对照见 [图解复查记录](research/diagram-review.md)。

## 5. 图片与授权

- **来源**：作品取自 Commons、维基百科文件页与馆藏官网，不按版权标签筛除或隐藏；逐张保留来源页的作者、授权或权利说明，不把非自由内容标为自由授权。百科阅读链接统一到中文维基百科；已核对的中文条目直接链接，没有条目时使用中文搜索，图片来源保留实际文件页或馆藏页。
- **获取**：`scripts/fetch-images.mjs` 读取作品图片配置；维基来源经 API 获取最大宽 1280px 大图和 320px 缩略图，小图沿用原始分辨率；馆藏官网使用已核对的图片及可选缩略图地址。写入 `public/images/works/<id>.<ext>`、`<id>.thumb.<ext>`，生成 `public/images/credits.json` 与 `CREDITS.md`。以返回的图片内容类型校验下载结果，不写入 HTML 错误页；相同大小图地址只下载一次。维基百科引用 Commons 文件时，即使本地文件页标为缺失，仍接受有效 `imageinfo`。
- **运行方式**：GitHub Actions 的“从维基共享资源取图”工作流（手动触发，可选全部重下或只处理指定作品），完成后自动提交并触发一次部署。本地有网络时也可以 `npm run fetch-images`。
- **人物肖像**：同一脚本还读取 `people.json`，按 `wiki`（英文维基百科条目名）经维基数据取该人物的图像属性（P18），同样检查授权，写入 `public/images/people/<id>.<ext>`（宽 480，人物卡片用）和 `<id>.thumb.<ext>`（宽 120，关系图节点用），署名记在 `credits.json` 的 `person:<id>` 键下。`portrait: false` 的人物跳过。
- **页面行为**：图片是否显示由 `credits.json` 决定，没有记录的作品显示首字占位，不会出现破图。大图下方显示作者、协议和来源链接。
- **完整性校验**：人物作品必须有完整作品引用；作品必须有介绍及图片或具体缺图原因；图片来源类型唯一，馆藏来源必须有 HTTPS 地址及署名；声明图片时必须存在署名记录、大图与缩略图。目前 423 件作品中有 422 件配图，仅《赛跑手拉达斯》因原作失传且无已知古代摹本保留文献说明。
- 部分 Commons 文件名来自早期整理，可能已改名或被替换；以取图工作流的报告为准，在 `works.json` 里换文件名后重跑。

### 图片加载与尺寸（2026-11-04）

- 原图与来源署名保留；`npm run optimize-images` 用 Sharp 从本地原图生成最长边 320px 的 WebP 小图和 960px 的展示图，记录在署名清单的 `optimized` 字段（路径及展示图宽高）。带源文件指纹的路径避免更新后命中旧缓存。构建与取图工作流自动生成，重复运行跳过已有版本。开发需要 Node.js 20.9+。
- 画海、年表与关系图使用小图；SVG 图片接近视口后才设置链接，画海离开视口时不请求新图片。首屏选中作品优先加载。
- 展厅、原作图解、并置、故事与看片台先显示小图，进入视口附近后下载展示图并解码，完成后替换；预先设置宽高保持原作比例和叠线位置。删除看片台启动时的下一张原图预取。
- 大图窗口先显示小图，再加载保留的原大图。快速切换或关闭会取消旧回调，避免旧作品覆盖新作品；大图失败时保留小图。减少动态效果时不做清晰化过渡。

## 6. 视觉与动效

- **配色**：主色取自艺术史上最贵的颜料**群青**（青金石），点缀色取**金箔**。浅色主题是“白天的展厅”：冷灰白墙面、墨色文字、群青强调；深色主题是“夜间的展厅”：蓝黑墙面、骨白文字、金箔强调。七个大阶段的颜色只用于数据编码（色条、边框、圆点），不用作装饰。
- **字体**：中文标题 Noto Serif SC（900 / 600）；西文标题、年份和罗马数字 Cormorant Garamond（含斜体）；正文 Noto Sans SC；数据小字 IBM Plex Mono。加载不到时回退系统字体。
- **版式**：内容最大宽 1200px，正文约 65 字一行；分区标题左侧是金色罗马数字，右侧标题与导语；卡片只用在需要“成为一个物件”的地方（展签、说明卡、图解面板），其余靠留白和细线分隔。
- **浮空画海**：深蓝黑背景与三层稀疏暖金星尘，桌面 72 粒、手机 36 粒，缓慢漂移并柔和明灭，少数亮星带细微星芒；拖动画海时各层产生轻微景差，始终位于作品后方且不拦截点击。粒子复用镜头位移变量，以 CSS transform 与 opacity 动画实现，共用暂停及离屏暂停；减少动态效果时保持静止。作品以细暖金边、下沿微光和柔和阴影呈现，远处较小且较暗，近处较大且清晰。图片完整显示，不裁切；首屏只加载小幅预览，大图按点击加载。标题区留白，浅色主题下序厅仍保持夜色。
- **动效**：序厅的轻微漂浮、展厅切换的淡入、大图切换。漂浮由 CSS transform 实现；画海镜头移动、调视距及滑停期间用 requestAnimationFrame 投影 DOM 图片，静止时停止逐帧 JavaScript，不使用 WebGL 或深度缓冲；全部遵守 `prefers-reduced-motion`。

## 7. 技术结构

```
src/
├── main.ts              启动：加载体系、写入配色、渲染页头页脚、初始化各分区；署名清单异步到达后重绘
├── content.ts           用 import.meta.glob 打包 content/ 下的 JSON；运行时读取 credits.json
├── state.ts             全局状态（当前体系、展厅、署名）与跨模块动作（goPeriod、openWork…）
├── types.ts             内容数据类型
├── lib/dom.ts, color.ts 小工具：转义、存储、拖动、分段按钮、颜色插值
├── lib/navigation.ts    站内历史与阅读上下文快照，保留既有 hash 深链接
├── sections/            hero（画海交互）、hero-space（布局与透视投影）、timeline、relay（艺术中心地图）、hall、pendulum、comparisons、sizes、wall、lightbox
├── assets/relay-land.svg Natural Earth 公有领域海岸线，来源与简化方式写在文件注释中
├── diagrams/            图解接口、注册表、各体系实现
└── styles/main.css      样式（颜色全部走 CSS 变量，浅色 / 深色两套）
```

`sections/mobile.ts` 与 `styles/mobile.css` 只用于窄桌面窗口的长卷适配。手机页层在 `src/mobile/`：`app.js`（外壳、导航栈、历史、各页面与时光带）、`mobile.css`、`context.ts`（脉络页内容，复用图解）。共用既有内容、搜索与图解，不引入路由框架、移动端数据副本或新的运行依赖。

- **构建**：Vite + TypeScript（strict），`base: "./"`，产物可部署在任意子路径。`npm run build` 先跑类型检查和内容校验。
- **部署**：推到或合入 `main` 后，GitHub Actions 校验并构建一次，同一份产物发布到 GitHub Pages，并用专用 deploy key 提交到 `tumars/ferecord/main` 的 `sites/main/public/art-history-atlas/`，由主站 EdgeOne Makers 发布。同步只替换该目录（包括清理旧哈希资源），保留其他主站文件；`source-version.txt` 记录源码 SHA。构建失败不会发布，主站并发提交先 rebase，冲突直接失败；手动运行 `deploy.yml` 可重试。密钥存放在 Actions secret `FERECORD_DEPLOY_KEY`，权限范围为 ferecord 仓库，不复用个人令牌。
- **记忆**：localStorage 记住上次的展厅和体系，读写失败不影响页面。
- **字体**：Noto Serif SC / Noto Sans SC / JetBrains Mono（Google Fonts），加载不到时回退系统字体。

发布工作流按路径过滤 push：源码、内容、公开资源、构建输入或发布工作流变化才自动构建；纯 README/设计文档修改不触发同步，以节省主站构建额度。手动运行可强制发布。

## 8. 扩展到其他体系

1. 在 `content/traditions/<id>/` 建 `tradition.json`、`periods.json`、`works.json`（其余可选），在 `site.json` 的 `traditions` 里登记。
2. 背景行可复用 `content/context/` 下已有的，也可以新建（如“日本时代”）。
3. 需要图解时在 `src/diagrams/<id>/` 实现并在 `src/diagrams/index.ts` 注册；没有图解也能运行。
4. `npm run validate` 检查引用，`npm run fetch-images` 或取图工作流补图。

## 9. 已知简化

- 年代多为约数，作品取一个代表年份定位（如“约 1503–1519”取 1503）。
- “理性与激情”的 `mood` 是整理框架，不是学术定论。
- 背景行的分期是概括，用来对照，不是严格断代。
- 界面只有中文；类型和目录结构为日后加英文留了空间，但目前没有国际化层。
